# ADR-0001: 项目概述（Bevy 迁移版）

状态：接受

日期：2026-10-19（自原 Godot 版 ADR-0001 2026-07-08 迁移改写）

> 本 ADR 最大化保留原 Godot 版设计决策，仅对引擎相关条目做 Bevy 映射改写。原文见 `E:\play\Godot\heads_up\docs\ADR-0001-project-overview.md`。

## 上下文

Heads-Up 是一个第一人称无尽散步体验游戏，核心体验是玩家抬头仰望天空，欣赏天际线的剪影与黄昏天色的变化。游戏采用过程化生成技术，随玩家行走动态生成世界，营造无尽探索感。原 Godot 版因测试效率低、Agent 开发体验受限，决定迁移到 Rust/Bevy（迁移决策见 ADR-0005）。

## 决策

### 核心体验（不变）

- **视角**: 第一人称，玩家习惯抬头看天
- **玩法**: 漫步探索，无目标、无挑战、无失败
- **主题**: 在无尽世界中闲逛，欣赏天空、树影与城市天际线

### 视觉风格

- **天色**: 黄昏主题，但动态变化，不固定使用单一 HDRI
- **天空技术**: 【迁移改写】Bevy 0.20 内置物理基大气散射（`Atmosphere`）+ bevy_elements（详见 ADR-0003），替代原 sky-3D Godot 插件
- **天气**: 保持晴朗黄昏，不引入天气变化；bevy_elements 的 WeatherDirector 锁定晴朗/低云量，不启用其雨雪雷电调度
- **天空元素**: 随机云、星星、月亮，后期可扩展飞鸟、飞机等随机元素（bevy_elements 已内置星空与月相，直接满足）
- **树木**: 使用现有资产（乔木为主，5 种，导出 glTF）随机抽取，支持季节变化（树叶密度变化），风的扰动是视觉重点
- **风的技术方案**: 【迁移改写】`MaterialExtension` 顶点着色器（WESL）驱动树的摇动，保留原顶点色 R 通道控制摆动强度的艺术接口
- **建筑**: 混合三种老旧建筑风格（不变）
  - 中式老城区（占比约 50%）：低矮坡屋顶，1-3 层
  - 旧公寓楼（占比约 30%）：方块状，4-6 层
  - 旧厂房（占比约 20%）：高耸体量+烟囱，6 层以上
  - 比例可根据效果在开发中调整
- **建筑制作**: 用户在 Blender 中建模模块，导出 glTF，在 Bevy 中通过程序化材质（`StandardMaterial` 扩展）调整老旧质感
- **天际线**: 由树和建筑顶部剪影组成，主要被仰望视角观赏
- **后期效果**: Bloom、色调映射（ACES）、景深（DoF，用 Bevy 内置 DepthOfField）、色差（CA，0.20 无内置，用 `FullscreenMaterial` 自写——见 ADR-0003 方案 B），具体强度在开发中根据实际效果调整

### 世界生成（不变，实现语言改为 Rust）

- **地图范围**: 约 2km × 2km，对应约 1 小时的散步距离
- **地图边界表现**: 生成地图时即确定边界，玩家不能越界（负形街道碰撞实体围合），但能看到界外的物体
- **生成策略**: 混合生成 — 开局由 seed 一次性生成路径拓扑，行走时流式实例化物体 — 详见 ADR-0002
- **路径拓扑**: 环路导向的网络结构，避免长死胡同，形成多条环线可探索
- **路径结构**: 随机生成可行走的路径地图，路径为线性街道，有宽度，节点处放大为小广场等空间
- **放置规则**: 树木、建筑等物体围绕路径放置，从路径可见
- **持久化**: 探索过的路径记录在存档中，返回时保持一致
- **探索范围**: 地图有边界，玩家可逐步探索直至全部走完
- **季节**: 由玩家在初始化地图时指定，也可选随机（单局游戏中不动态变化）
- **季节种类**: 四季分明 — 春（新绿嫩叶）、夏（茂密深绿）、秋（金黄落叶）、冬（枯枝无叶）

### 玩家移动（不变）

- **移动方式**: 普通散步
- **控制方式**: 键盘 WASD + 鼠标控制视角（主）；支持手柄
- **速度范围**: 1.2-2.0 m/s，支持在游戏内通过按键动态调整
- **视角高度**: 正常站立高度（约 1.6-1.7m）

### 存档系统（序列化从 JSON+GDScript 改为 serde）

- **对应关系**: 一个存档对应一张地图
- **存档内容**: 种子（seed）+ 探索标记位图
- **种子**: 可随机生成也可由玩家手动输入（支持复制/分享 seed）
- **地图复用**: 探索完成后，玩家可选择继续在同一地图中散步，或重新开始生成新地图
- **多存档**: 支持同时保存多个存档，各有不同 seed 的地图

### 开局流程（不变）

- 进入游戏 → 菜单界面（Bevy UI 实现，非自动生成世界，菜单驱动）
- "开始新的散步"：可指定 seed（可选）和季节
- "读档"：加载已有存档继续探索

### 交互设计（不变）

- **移动**: 玩家可控制前后移动和转向
- **视角限制**: 鼠标控制视角，左右各约 10°，仰角 40-60° 范围，不能看到地面
- **碰撞**: 走到地图边界处被挡住不可走动
- **碰撞行为**: 被环境物体阻挡，不能穿墙

### 声景（不变）

- **主声**: 环境音为主
- **配乐**: 极少量、克制的短时间配乐，不持续播放

### 技术目标

- **目标平台**: PC（Windows 优先）
- **性能目标**: 普通笔记本中低端独立显卡可流畅运行（2-4GB VRAM），30fps+

## 后果

- 天空系统迁移到 Bevy 0.20 Atmosphere + bevy_elements —— 见 ADR-0003
- 世界生成框架用 Rust 实现，确定性约束（rand_chacha）比 GDScript 更严格 —— 见 ADR-0002
- 风的顶点着色器需用 WESL 重写，保留顶点色接口 —— 见 ADR-0004
- 树资产需从 .tscn/.blend 重新导出为 glTF（吸取嵌入 >17MB 的教训）
- 需要视角限制系统（水平/垂直角度钳制，纯 Rust 数学）
- 需要路径地图随机生成算法（环路型街道网络，Block 优先）
- 存档系统用 serde JSON，结构不变
- 性能预算需控制在低端独立显卡范围内
